# Chatkeeper

Приватный Telegram-бот для архива личных переписок на базе **Telegram Business API**.
Бот подключается к вашему собственному аккаунту (через официальные настройки
Telegram Business) и ведёт зашифрованный архив ваших диалогов, а также показывает,
что собеседники удаляют и редактируют.

В комплекте — веб-панель (React) для удобного просмотра переписок.

## Возможности

- 🗂 **Архив сообщений** — сохраняет входящие и исходящие сообщения из личных
  чатов. Тексты шифруются перед записью в базу (AES-256-GCM).
- 🗑 **Детекция удалений** — когда собеседник удаляет сообщение, бот присылает вам
  его содержимое: текст, автора, дату и вложение (если было).
- ✏️ **История правок** — при редактировании сохраняет прежнюю версию и
  показывает «было → стало».
- 📸 **Перехват исчезающих медиа** — если ответить (reply) на view-once фото/видео,
  бот скачивает копию, пока файл ещё доступен.
- 🧹 **Автоочистка (TTL)** — фоновый воркер удаляет записи старше заданного срока,
  чтобы база не разрасталась.
- 🌐 **Веб-панель** — просмотр диалогов как в мессенджере: удалённые подсвечены,
  правки с историей, медиа прямо в ленте. Вход по паролю (JWT).
- 💬 **Команды в боте** — `/start`, `/status` (состояние подключения),
  `/stats` (сколько сообщений сохранено).

> Какие чаты логировать (и какие исключить) выбирается в нативных настройках
> Telegram Business при подключении бота.

## Технологии

- **Backend:** Go, PostgreSQL (pgx + sqlc), миграции goose, шифрование AES-256-GCM
- **Telegram:** `github.com/go-telegram/bot` (Business API)
- **Frontend:** React + Vite + Tailwind CSS
- **Деплой:** Docker + Docker Compose, Caddy (авто-HTTPS)

## Быстрый старт (локально)

Нужны Go 1.26+, Node 20+ и Docker (для PostgreSQL).

```bash
# 1. Настройки
cp deploy/.env.example deploy/.env
#   заполните BOT_TOKEN, сгенерируйте ключи:
#   ENCRYPTION_KEY = openssl rand -hex 32
#   JWT_SECRET     = openssl rand -hex 32
#   задайте ADMIN_PASSWORD; для локального запуска MODE=polling

# 2. База данных
make db-up

# 3. Бот + REST API (на :8080)
make run

# 4. Веб-панель (dev-сервер на :5173)
cd frontend && npm install && npm run dev
```

Затем в Telegram подключите бота: **Настройки → Telegram для бизнеса → Чат-боты**.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather (нужен Business Mode) |
| `DB_URL` | Строка подключения к PostgreSQL |
| `ENCRYPTION_KEY` | Ключ шифрования текстов (32 байта hex) |
| `MODE` | `polling` (локально) или `webhook` (прод) |
| `WEBHOOK_URL` | Публичный HTTPS-адрес (для webhook) |
| `TTL_DAYS` | Через сколько дней удалять старые сообщения |
| `API_ADDR` | Порт REST API веб-панели |
| `ADMIN_PASSWORD` | Пароль входа в веб-панель |
| `JWT_SECRET` | Секрет для подписи токенов панели |

Полный список — в [deploy/.env.example](deploy/.env.example).

## Команды Makefile

| Команда | Что делает |
|---|---|
| `make run` | Запустить бота + API локально |
| `make db-up` / `make db-down` | Поднять / остановить PostgreSQL в Docker |
| `make test` | Прогнать тесты |
| `make build` | Собрать бинарник |
| `make genkey` | Сгенерировать ключ шифрования |
| `make deploy` | Собрать и запустить прод-стек |

## Приватность

Бот работает только с вашим собственным аккаунтом через официальный API и
хранит данные на вашем сервере. Тексты шифруются в базе. При этом он сохраняет
сообщения собеседников, включая удалённые и исчезающие, — используйте инструмент
ответственно и с учётом законов о приватности переписки в вашей юрисдикции.
